About This Website

This website was built as a simple, beginner-friendly project using only plain HTML, without any CSS or JavaScript. It has four pages: Home, Profile, Gallery, and About, all linked together through a basic navigation list.

The goal of this site is to practice the basic structure of HTML documents, including headings, paragraphs, lists, links, and images.
